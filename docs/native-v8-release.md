Recycler facility onboarding is now available in the same native Aggregator/Recycler app.

- Recycler → Your facility: complete Business, Services and Documents, with drafts saved on the phone.
- Attach private PDF/JPG/PNG evidence and submit it to Freedom Value operations for review.
- See pending, approved, changes-required or expired status, review notes and history. Correct and resubmit details when needed.
- Operations staff review evidence from ERP → Facility reviews and record a reason, evidence source and approval expiry.
- Approval applies to the submitted material categories. Expiry, withdrawal and resubmission restrict new business while preserving existing orders.
- Login/Signup, explicit role selection, aggregator photo/lot creation, Gemini, invoices, external settlement records and the Cloudflare backend remain available.

Install over native v7 without uninstalling. The package and permanent signing certificate are unchanged. Screenshots use isolated test data.

This is a demo release. Freedom Value review is not government certification. SMS verification and password recovery are not configured; retain your password. Physical camera/document picker and a complete two-party phone transaction still need checking.
