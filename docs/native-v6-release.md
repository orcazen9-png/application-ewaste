E-Waste Marketplace native Android UI update for collector and recycler accounts.

- Persistent navigation, clear primary actions, outlined fields and grouped content.
- Collector home with a prominent Create a lot action and saved-lot status.
- Photo → Details → Review lot flow with autosaved drafts and a fixed next/save action. Camera and upload are available before the form; manual category selection remains available.
- Photo identification uploads the selected photo without submitting an unfinished lot. Suggested categories still require human confirmation.
- Earnings dashboard separates confirmed receipts, pending transfers, quotes, invoices and outstanding dues. Empty accounts show an empty state, without sample money or activity.
- New controls include Hindi and Marathi translations. English UI checks include a compact Android viewport with larger system text.

Install the APK over native v5 without uninstalling. The package and permanent signing certificate are retained. The release workflow tests v5 → v6 installation with draft, photo, encrypted session and account-cache preservation. Public preview screenshots use isolated test accounts with zero payments; they do not depict live transactions.

The Cloudflare backend, private D1 storage, individual invitations and existing records are retained. This remains a demo: payments are recorded externally, notifications are periodic, SMS sign-in is not configured and recycler demo access does not certify a facility. Physical camera, document picker and a complete two-party transaction still need device verification.
