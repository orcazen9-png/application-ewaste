E-Waste Marketplace now starts with Log in and Sign up, followed by an explicit Aggregator or Recycler choice.

- Create an individual username/password account in either role. Recycler facilities start as unverified; registration does not grant trading verification.
- Existing signed-in users see a named Continue as Aggregator/Recycler action. No automatic entry into the aggregator workspace.
- Switch accounts from Profile. Failed sign-in attempts keep the existing session available.
- Existing invitation users can choose Profile → Set up username and password, keeping the same account, lots, orders and payments. Invitations remain supported; choosing the wrong role does not consume the code.
- English, Hindi and Marathi controls. The photo-first lot flow, recycler buying workspace, invoices, settlement records and Cloudflare backend remain available.

Install over native v6 without uninstalling. This release uses the same package and permanent signing certificate. Screenshots show isolated test accounts.

This is a demo release. SMS verification and password recovery are not configured. Save your password securely. New recycler facilities require separate review before trading; no government verification is implied. Physical camera/document picker and complete two-party transaction checks remain outstanding.
